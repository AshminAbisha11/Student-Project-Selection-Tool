# Student Project Selection Tool 🎓

A web-based tool designed to streamline the process of student project selection at Aston University. It supports role-based access for students, supervisors, and admins, enabling project browsing, preference submission, proposal handling, and student allocation.

---

## Features

- 🔐 User authentication with role-based access (Student, Supervisor, Admin)
- 🧑‍🎓 Student dashboard: Browse projects, submit preferences, and send proposals
- 👨‍🏫 Supervisor dashboard: Manage projects, review proposals, and view allocated students
- 📋 Admin-level control (future extension)
- 🗃️ Centralized project listing with filters (by supervisor, topic, etc.)
- 📄 Proposal submission and tracking
- 🧠 Designed with HCI principles for usability

---

## Tech Stack

- **Frontend:** React.js
- **Backend:** JavaScript with Express
- **Database:** PostgreSQL 
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub
